## 2025-02-18 - POS Cashier Keyboard Navigation & Accessibility
**Learning:** Cashiers and store operators in high-throughput retail environments heavily optimize for speed and ergonomic efficiency, preferring keyboard shortcuts over mouse/trackpad interactions. Providing global keydown listeners (e.g. F2 for search, F8/F9 for checkout, Escape to cancel/close modals) coupled with explicit visual HTML `<kbd>` helpers significantly improves task completion times, reduces operator fatigue, and enhances screen reader and keyboard accessibility (a11y) inside busy point-of-sale systems.
**Action:** Always complement heavy user-interaction screens (such as cashiers, booking engines, or dashboards) with standard helper keyboard shortcuts, clear visual keyboard badges, and robust ARIA labels for icon-only components.
