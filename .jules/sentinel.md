## 2026-03-01 - [Production Authentication Bypass via Default User Fallback]
**Vulnerability:** The central Express server's authentication middleware allowed an unauthenticated client to bypass security checks entirely and gain full administrative (Manager) privileges by automatically falling back to the master manager user (ID '001') if no credentials were provided, without verifying the current environment status.
**Learning:** This fallback was originally designed to facilitate rapid local development, testing, and offline POS simulation. However, failing to wrap this bypass block in an environment check (e.g., verifying `process.env.NODE_ENV !== 'production'`) left the system exposed to trivial remote auth bypass in production environments.
**Prevention:** Always ensure that any fallback mechanism, test accounts, bypass switches, or debug gateways are explicitly restricted to non-production environments by gating them with strict checks like `process.env.NODE_ENV !== 'production'`.
